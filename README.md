# Exercício para conclusão de disciplina Automação de testes web E2E - Pós Graduação em Automação de testes - PGATS

Projeto de automação de testes da aplicação https://automationexercise.com/ utilizando cypress.

## Comandos 

- Instalação das dependências do projeto: npm install
- Execução headless: npx cypress run --spec "cypress/e2e/automation-exercise.cy.js"
- npx cypress open
